# Auditoría y configuración (auditlog / config)

Auditlog conserva el usuario, registro, acción, fecha y detalles de los cambios registrados. Config centraliza rutas, sesiones, seguridad y base de datos. SQLite es predeterminada; PostgreSQL es una alternativa configurable. Producción requiere clave privada, hosts permitidos, HTTPS y tabla de caché. No se ha verificado un despliegue de producción.
